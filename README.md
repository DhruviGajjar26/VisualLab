# VisualProgrammingLab

VisualProgrammingLab is a personal project for learning and understanding programming concepts in a more visual and interactive way.

The main idea is simple: instead of only reading about a concept or looking at code, I want to see what is actually happening when the code runs.

For example, for a simple variable:

```csharp
int age = 25;
```

the application can explain what a variable is and show how the value is stored and used through a simple visual animation.

## What I Want to Build

For each programming topic, the application will try to combine:

* Basic concept explanation
* Code examples
* Visual representation
* Simple animations
* Step-by-step execution
* Small practice examples

The idea is to make programming concepts easier to understand and remember.

## Initial Topics

I will start with basic C# concepts:

* Variables
* Data Types
* Operators
* Conditions
* Loops
* Methods
* Arrays

After that, I may add other topics such as:

* OOP
* Data Structures
* Algorithms
* Database
* Git
* Operating Systems
* IoT
* Networking

## Example

For different concepts, the visualization could work like:

```text
Variable      → Memory / Value visualization
If-Else       → Decision flow
Loop          → Repeated execution
Method        → Method call flow
Array         → Index and memory visualization
Stack         → Stack operations
```

These visualizations will be reused wherever possible so that new topics can be added more easily.
